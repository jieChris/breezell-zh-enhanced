# Breezell 简体中文增强包

## Goal

交付一个可安装的本地 `.vsix`，为 Breezell 1.112.0 补齐关键简体中文界面，并支持安全恢复。

## Scope

- 扫描 Breezell 核心 NLS、自定义设置页和 `openai.chatgpt` 扩展中的未汉化文本。
- 提供“应用汉化”“恢复汉化”“查看状态”三个命令。
- 修改任何目标文件前创建原始备份；重复应用必须幂等。
- 输出可审计的英文清单、中文映射和 `.vsix`。

## Out of Scope

- 翻译 Breezell、Codex、MCP、模型、厂商和代码标识符等专名。
- 翻译第三方扩展内容。
- 自动后台修改文件。

## Acceptance Criteria

- [x] 核心 NLS 自定义条目已扫描并有稳定键标识。
- [x] 关键硬编码文本有精确匹配补丁。
- [x] 应用、恢复和状态逻辑有可运行检查。
- [x] 补丁拒绝未知应用或不兼容文件，不静默部分写入。
- [x] 生成的 VSIX 可由 Breezell 安装。
- [x] 安装后通过 Breezell 内置界面验证关键中文。
